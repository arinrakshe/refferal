## What You Need To Produce

By demo time, your team should have:

- A team name.
- A project title.
- One selected challenge track.
- A clear healthcare workflow problem.
- A working prototype, mockup, notebook, script, app, or workflow demo.
- A README or submission note explaining how to inspect it.
- Safe data: synthetic or de-identified only.
- A clear explanation of where AI is used.
- One trust, safety, or transparency mechanism.
- One measurable success metric.
- A 3-minute demo.

## The Four Tracks

| Track | Short Description |
|---|---|
| Improve Patient Experience | Help patients prepare, navigate, understand, follow up, or take action |
| Improve Encounter Experience | Help clinicians or care teams before, during, or after an encounter |
| Reduce Administrative Burden | Reduce repetitive manual work, routing, triage, summarization, or documentation |
| Improve Data Liquidity, Trust, and Transparency | Make data easier to exchange, inspect, validate, explain, or trust |
