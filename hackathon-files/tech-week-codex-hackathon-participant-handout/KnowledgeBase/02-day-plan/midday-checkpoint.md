# Midday Checkpoint

Checkpoint time: 12:30-13:00 EDT.

The midpoint is where teams make the project real enough to finish. It is not a status ceremony; it is a scope correction point.

## Submit Or Be Ready To Share

- Team name.
- Participant names.
- Track.
- Project title.
- One-sentence problem.
- What is working.
- Biggest blocker.
- Planned final demo.
- Data source.
- Trust/safety/transparency mechanism.

## Midday Decision

At 12:30, ask:

```text
Can we demo this by 15:30?
```

If the answer is no, cut scope.

## Good Scope Cuts

- Use saved model output instead of live calls.
- Demo one record instead of many.
- Use a CLI instead of a UI.
- Use screenshots for one broken screen.
- Replace a real integration with a mock.
- Show one user path instead of three.

## After Checkpoint

Spend the afternoon on:

- Stabilizing the main demo path.
- Writing the README.
- Explaining safety and limitations.
- Preparing the final script.
- Making a backup demo.
