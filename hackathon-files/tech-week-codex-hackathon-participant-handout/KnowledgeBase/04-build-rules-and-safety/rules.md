# Rules

## Main Rules

- Use synthetic or de-identified data only.
- Do not use real PHI.
- Do not expose secrets, tokens, passwords, or API keys.
- Do not build an autonomous clinical decision-maker.
- Include human review for clinical, operational, or high-risk recommendations.
- Disclose AI usage.
- Credit third-party code, data, and assets.
- Be honest about limitations.

## Allowed

- Codex, ChatGPT, and approved event tools.
- Synthetic healthcare data.
- De-identified examples.
- FHIR-like sample resources.
- Synthea-style records.
- Prompt templates.
- Starter apps, wireframes, notebooks, scripts, and demos.
- Open-source packages with appropriate credit.

## Not Allowed

- Real PHI.
- Customer-identifiable data.
- Private production exports.
- API keys in repos or prompts.
- Screenshots with secrets.
- Unsupported clinical claims.
- Autonomous diagnosis, treatment, or clinical action.

## Required In Your Demo Or Submission

- Data inputs.
- Where AI is used.
- What humans review.
- One trust/safety/transparency mechanism.
- One success metric.
- Known limitations.

## If You Are Unsure

Ask a TA before using questionable data or making a clinical claim.
