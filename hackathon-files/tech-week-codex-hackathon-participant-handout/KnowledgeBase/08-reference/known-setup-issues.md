# Known Setup Issues

Planning context from related AI training showed a few common setup problems. If any of these happen, ask a TA quickly.

| Issue | What To Do |
|---|---|
| Temporary license not active | Confirm account exists and ask a TA to escalate |
| Wrong account email | Use the email provided for license setup |
| CLI or tool version issue | Ask for the recommended version or fallback |
| OAuth or PAT issue | Check account identity and token scope |
| VS Code token exchange problem | Use a browser or CLI fallback if available |
| Endpoint stalls | Use saved outputs or mock responses while debugging |
| Desktop app disabled by admin policy | Use approved browser or CLI flow |

## Keep Moving

If setup blocks you for more than 10 minutes:

- Switch to mock data.
- Build the README and demo story.
- Generate saved example outputs.
- Ask a teammate to continue the prototype.
- Escalate through a TA.
