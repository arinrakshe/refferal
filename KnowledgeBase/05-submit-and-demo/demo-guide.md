# Demo Guide

## Format

- 3 minutes demo.
- 2 minutes judge Q&A.

## Recommended 3-Minute Structure

| Time | What To Say Or Show |
|---|---|
| 0:00-0:20 | Project name, track, user, problem |
| 0:20-0:50 | Current workflow and pain point |
| 0:50-2:10 | Prototype walkthrough |
| 2:10-2:35 | Data inputs and where AI is used |
| 2:35-2:50 | Trust/safety/transparency mechanism |
| 2:50-3:00 | Success metric and closing |

## Required Demo Elements

- User or stakeholder.
- Pain point.
- Before/after workflow.
- Data inputs.
- Where AI is used.
- One trust or guardrail mechanism.
- One success metric.

## Good Closing Sentence

```text
In one day, we built [prototype] to help [user] improve [workflow] by [AI-assisted improvement], with [guardrail] keeping the result reviewable.
```

## Be Ready To Answer

- What workflow does this improve?
- What data did you use?
- What did AI do?
- What did AI not do?
- How does a human review the output?
- What is the biggest limitation?
- What would you build next?
- What metric would prove value?

## Backup Demo

Prepare one:

- Screenshot.
- Short recording.
- Saved sample output.
- Static mock.
- Notebook output.

Do this even if the live demo works.
