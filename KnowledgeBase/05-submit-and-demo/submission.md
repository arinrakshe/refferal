# Submission

## When To Submit

Submit before final demos begin at 15:30 EDT unless organizers announce a different deadline.

The final submission form URL was not available in the planning summary. Use the submission link announced during the event.

## Required Fields

- Team name.
- Participant names.
- Track.
- Project title.
- Problem statement.
- Solution summary.
- Repo, artifact, app, notebook, or demo link.
- Setup or inspection instructions.
- Data inputs.
- AI usage.
- Trust/safety/transparency mechanism.
- Success metric.
- Known limitations.
- Third-party credits, if applicable.

## Accepted Artifact Types

- Git repo.
- Markdown README.
- Web app.
- CLI.
- Notebook.
- Script.
- Prototype screens.
- Workflow mock.
- Demo video.
- Slides or document artifact.

## Submission Checklist

- [ ] Link opens.
- [ ] README or explanation is present.
- [ ] Demo steps are clear.
- [ ] Data is safe.
- [ ] AI usage is disclosed.
- [ ] Trust/safety/transparency mechanism is named.
- [ ] Success metric is named.
- [ ] Limitations are included.
- [ ] Third-party sources are credited.
- [ ] No secrets or PHI are present.
