# Project Ideas

Use these as starting points, not constraints.

## Improve Patient Experience

- Patient-friendly visit prep assistant using synthetic appointment and history data.
- Follow-up instruction summarizer with questions-to-ask checklist.
- Medication terminology explainer using RxNorm/RxNav references.
- Synthetic claims explanation assistant.
- Appointment readiness checklist.

## Improve Encounter Experience

- Pre-visit brief from synthetic patient context.
- Care team handoff summarizer.
- Visit note draft helper with human review.
- Missing prep item detector.
- Clinical information timeline over synthetic records.

## Reduce Administrative Burden

- Message triage assistant for synthetic inbox examples.
- Prior authorization packet checklist.
- Manual document review summarizer.
- Work queue classifier.
- Draft response assistant with approval step.

## Improve Data Liquidity, Trust, And Transparency

- FHIR-like data quality inspector.
- Data provenance explainer for synthetic records.
- LOINC/RxNorm mapping helper.
- Missing-information warning layer for AI outputs.
- Trust report generator for generated summaries.

## Strong One-Day Project Pattern

```text
Input: one safe sample record or message
AI task: summarize, extract, classify, or draft
Guardrail: source display, human review, uncertainty, or missing-info warning
Output: a clear before/after workflow
Metric: time saved, quality improved, risk reduced, or confidence increased
```
