# Account And Access Checklist

## Before You Build

- [ ] You can sign in to the required ChatGPT/Codex account.
- [ ] Temporary Pro ChatGPT/Codex access works, if you were told you would receive it.
- [ ] You can connect to the event network.
- [ ] You know how to reach a TA.
- [ ] You have access to any provided starter data or API endpoint.
- [ ] You know where final submissions will be collected.

## Critical License Note

If you are an external user receiving temporary Pro ChatGPT/Codex access, your account must exist before the license can be applied. Planning context says there is no alternate method for applying the temporary license to an account that has not been created.

If your access does not work, tell a TA:

```text
Name:
Team:
Account email:
What tool is blocked:
Exact error:
When you created the account:
```

## Do Not Share Secrets

Do not paste or commit:

- API keys.
- Passwords.
- Personal access tokens.
- Private credentials.
- Real PHI.
- Customer-identifiable data.
- Screenshots containing sensitive values.

## If Access Fails

Keep building with:

- Mock data.
- Saved example outputs.
- Static screenshots.
- A local-only prototype.
- A README that explains the intended live path.

Do not let one access issue stop the whole team from preparing a demo.
