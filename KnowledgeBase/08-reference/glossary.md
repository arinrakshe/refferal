# Glossary

| Term | Meaning |
|---|---|
| AI Gateway | Governed model endpoint path for custom integrations |
| BCDA | Beneficiary Claims Data API, referenced as a starter data category |
| Codex | AI coding agent/tool used for development assistance |
| De-identified data | Data stripped of identifying information according to applicable policy |
| FHIR | Healthcare interoperability standard for resources and workflows |
| Guardrail | A control that limits unsafe, incorrect, or unsupported AI behavior |
| Human review | A human checkpoint before acting on AI output |
| LOINC | Standard terminology for labs and clinical observations |
| MVP | Minimum viable prototype |
| PHI | Protected health information; do not use it in this hackathon |
| RxNorm/RxNav | Medication terminology/reference resources |
| Synthea | Synthetic patient data generator |
| TA | Technical assistant or mentor |
